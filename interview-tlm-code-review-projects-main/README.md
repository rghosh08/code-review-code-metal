# Code Review Projects

This archive consists of two small projects:

1. [sensor_data_pipeline](./sensor_data_pipeline/README.md)
2. [compiler-cache](./compiler-cache/README.md)

One is implemented in Python, and the other is implemented in C++. Each project has a REQUIREMENTS.md file, which lays out the requirements, and a README.md, which describes the implementation and how to run it. Please take a look at each and provide code/design review-style feedback.

Given that this isn't a PR or design document to comment on, it may be less ergonomic to review code, so please feel free to format your comments in any way that is convenient for you (separate document, like a Markdown file, a PR consisting of inline comments, etc.).

We prefer this be returned by you creating a private github repo and inviting the people below to it:
